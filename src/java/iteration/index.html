for Loop

When you know exactly where a loop starts, where it stops, and how it updates, the for loop is the cleanest tool for the job.

Share with others, it's free

Anatomy of a For Loop

Logic Mapping

Suppose we already know exactly:

  • where the repetition starts,
  • where it should stop,
  • and how the value changes.
flowchart LR A["Initialization"] --> B{"Condition"} B -->|True| C["Execute Code"] C --> D["Update"] D --> B B -->|False| E["Stop"] style B fill:#DCECEF,stroke:#245F73,stroke-width:2px,color:#1B4A5A style E fill:#f1f5f9,stroke:#94a3b8
Syntax 
for (initialization; condition; update) {
    // code to repeat
}

These three pieces are so common when working with counting loops that Java provides a loop structure that places them together. That loop is the for loop.

Example 1: Repeating Through a Range

Logic Mapping

Suppose a program needs to calculate the total of the numbers from 1 to 5.

We need a variable that keeps track of the total. Each time the loop runs, the current number is added to that total.

flowchart TD A["total = 0"] --> B["number = 1"] B --> C{"number <= 5"} C -->|Yes| D["total = total + number"] D --> E["number++"] E --> C C -->|No| F["Display total"] style C fill:#DCECEF,stroke:#245F73 style F fill:#f1f5f9,stroke:#94a3b8

Let's follow the values.

At the beginning: total = 0
total = 0 + 1 → total = 1
total = 1 + 2 → total = 3
total = 3 + 3 → total = 6
total = 6 + 4 → total = 10
total = 10 + 5 → total = 15

Java Implementation

Main.java
Copy the code, paste it in your IDE, run it, break it, learn from it. 
public class Main {
    public static void main(String[] args) {
        int total = 0;
        
        for (int number = 1; number <= 5; number++) {
            total = total + number;
        }
        
        System.out.println("Total: " + total);
    }
}
$ java Main
Total: 15

Technical Note: Notice there are two important variables. number controls the loop iterations, while total remembers the accumulated result outside the loop scope.

Example 2: Finding a Value

Logic Mapping

So far, the for loop has been used to process every number in a range. But sometimes the goal is different. Suppose we want to check whether a particular number exists between 1 and 10.

Let's say we are looking for: targetNumber = 7

flowchart TD A["targetNumber = 7"] --> B["number = 1"] B --> C{"number <= 10"} C -->|Yes| D{"number == targetNumber"} D -->|Yes| E["Display 'Found'"] D -->|No| F["number++"] F --> C E --> G["Continue Program"] C -->|No| H["Display 'Not Found'"] style C fill:#DCECEF,stroke:#245F73 style D fill:#DCECEF,stroke:#245F73 style E fill:#bbf7d0 style H fill:#fecaca

The logic is straightforward: Start at 1. Check each number. If the answer is yes, the value has been found. If the answer is no, move to the next number.

Java Implementation

Main.java
Copy the code, paste it in your IDE,run it, break it, learn from it. 
public class Main {
    public static void main(String[] args) {
        int targetNumber = 7;
        boolean found = false;
        
        for (int number = 1; number <= 10; number++) {
            if (number == targetNumber) {
                found = true;
                break; // Stop immediately
            }
        }
        
        if (found) {
            System.out.println("Number found.");
        } else {
            System.out.println("Number not found.");
        }
    }
}
$ java Main
Number found.

What does break mean?
break tells Java to stop the loop immediately. There is no reason to continue checking numbers once the target is found.

Why use found?
The variable boolean found = false; acts as a memory flag that remembers the state of a decision made inside the loop so we can evaluate it afterward.

Example 3: Skipping an Iteration

Logic Mapping

Sometimes a loop should not stop completely when a particular situation occurs. Instead, the program may simply want to skip the current iteration and continue with the next one.

Suppose we want to display the numbers from 1 to 10, but we do not want to display 5.

flowchart TD A["number = 1"] --> B{"number <= 10"} B -->|Yes| C{"number == 5"} C -->|Yes| D["Skip current iteration"] D --> E["number++"] E --> B C -->|No| F["Display number"] F --> E B -->|No| G["Stop"] style B fill:#DCECEF,stroke:#245F73 style C fill:#DCECEF,stroke:#245F73 style D fill:#fca5a5 style G fill:#bbf7d0

Notice the difference from break. When number becomes 5, the program does not leave the loop. It simply skips the current iteration and continues normally.

Java Implementation

Main.java
Copy the code, paste it in your IDE,run it , break it, learn from it. 
public class Main {
    public static void main(String[] args) {
        for (int number = 1; number <= 10; number++) {
            if (number == 5) {
                continue; // Skip current iteration
            }
            System.out.println(number);
        }
    }
}
$ java Main
1
2
3
4
6
7
8
9
10

break vs continue

  • break means: Stop the loop completely.
  • continue means: Skip this iteration and keep the loop going.
